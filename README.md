# 🌐 Personal Portfolio Website

Welcome to my personal portfolio website! This project showcases my **skills, projects, education, experience, and contact information** through a modern and responsive web interface.

🔗 **Live Website:**
https://manjumudhiraj.github.io/portfolio/

---

## 📌 About the Project

This portfolio website is designed to provide a professional overview of my journey as a **B.Tech Computer Science student and aspiring software developer**.

The website highlights my technical skills, featured projects, educational background, and ways to connect with me.

It is designed with a clean, modern interface and focuses on providing a smooth browsing experience across different devices.

---

## ✨ Features

* 🏠 **Home Section** – Introduction and personal overview
* 👩‍💻 **About Section** – Information about my background and interests
* 🛠️ **Skills Section** – Technical skills and technologies
* 💻 **Projects Section** – Showcase of my projects and development work
* 🎓 **Education Section** – Academic background
* 📬 **Contact Section** – Ways to connect with me
* 📱 **Responsive Design** – Works across desktop, tablet, and mobile devices
* 🎨 **Modern UI** – Clean and professional visual design
* ⚡ **Fast & Lightweight** – Optimized for a smooth browsing experience

## 🚀 Getting Started

To run this project locally:

### 1. Clone the repository

```bash

```

### 2. Navigate to the project folder

```bash
cd portfolio
```

### 3. Open the project

Open `index.html` in your preferred web browser.
